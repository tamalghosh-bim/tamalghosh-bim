03BIM × AI

Hours of drafting, turned into a few minutes of scripting.

I use AI to write and refine AutoLISP routines and Dynamo scripts for repetitive Civil 3D tasks. The engineering judgement stays with me; the clicking doesn't.

Every project has tasks that are the same a thousand times over: labelling crossings, checking cover depths, publishing sheet sets. I describe the task to an AI assistant, review and test the code it writes, then run it on the model and check the results.
